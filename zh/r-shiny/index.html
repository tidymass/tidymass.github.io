R shiny 使用说明

通过浏览器界面完成 LC-MS 数据处理与分析。本教程针对独立的 tidymassshiny 应用；桌面软件中的 Shiny tools 安装器请看 macOS/Windows 教程。

公开源码当前标记为 tidymassshiny 1.0.0。在线服务和 Docker 镜像可能使用不同构建，运行时请记录实际版本。

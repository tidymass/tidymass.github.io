R package 使用说明

从原始 LC-MS 文件到可复现的统计与通路结果。先了解数据结构，再按功能包逐步学习，最后运行完整 workflow。这里覆盖官网包目录中的 R 包；R Shiny 应用有独立教程。

  1. 安装与版本管理
  2. tidymass — 安装与管理包体系
  3. massdataset — 构建、查看与交换数据集
  4. massconverter — 转换厂商原始文件
  5. massprocesser — 峰检测与样品对齐
  6. masscleaner — 过滤、填补与归一化
  7. massqc — 质量评估与报告
  8. massdatabase — 获取与构建参考数据库
  9. metid — Feature 注释与谱图审查
  10. massstat — 探索变异与组间比较
  11. metpath — 通路与 feature 模块分析
  12. masstools — 分子式、谱图与 ID 工具
  13. MetNormalizer — 使用独立归一化流程
  14. 完整 LC-MS 分析工作流

图解：本章操作路线

峰表用户从安装与 massdataset 开始；原始仪器数据用户先阅读 massconverter 和 massprocesser。完整 workflow 负责把各阶段对象串起来，需要调整某一步时再查相应包的章节。
